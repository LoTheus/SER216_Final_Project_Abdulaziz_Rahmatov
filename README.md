# Digital Parking Permit System
## SER216 Final Practical Project
**Student:** Abdulaziz Rahmatov

## Project Description
A university digital parking permit system that allows students and staff 
to register vehicles, request parking permits, check available parking 
zones, and report parking issues. Security staff can verify permits and 
update violation records.

## Tools Used
- Google Docs — project report writing

- diagrams.net — workflow diagram
- GitHub — version control and project evidence

## Workflow
Vehicle Registration → Permit Request → Zone Check → 
Permit Approval → Parking Verification
